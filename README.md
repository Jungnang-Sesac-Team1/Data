# 🕸️ 소상공인24 공고 자동화 크롤러 & DB 파이프라인

## 📖 개요
**소상공인24** 웹사이트의 지원사업 공고를 자동으로 수집하는 파이프라인입니다.
지정된 키워드 리스트를 기반으로 검색을 수행하고, 상세 페이지의 **제목, 본문, 메타데이터**를 추출하며, **첨부파일(HWP, PDF 등)**을 자동으로 다운로드하여 저장합니다. 최종적으로 수집된 정형 데이터는 **Database**에 적재되어 분석 및 서비스에 활용될 수 있도록 구성합니다.

## 🚀 주요 기능 (Features)
1. **키워드 기반 자동 검색**: 리스트에 있는 공고 제목을 입력하여 검색 및 상세 페이지 진입
2. **상세 정보 수집**: 공고 제목, URL, 본문 전체 내용(Text) 스크래핑
3. **첨부파일 자동화**:
   - 게시글 내 첨부파일 자동 감지 및 다운로드
   - 다운로드 시 발생하는 팝업창 자동 제어 (Headless 환경 대응)
4. **데이터 전처리**: 제목 내 말줄임표(...) 제거 및 특수문자 정제
5. **DB 적재 (ETL)**: 수집된 데이터를 CSV 백업 후 RDBMS(Oracle/MySQL)에 적재

## 🛠️ 기술 스택 (Tech Stack)
- **Language**: Python
- **Web Scraping**: Selenium WebDriver (Chrome)
- **Data Processing**: Pandas
- **Database**: MySQL (환경에 맞춰 설정)
